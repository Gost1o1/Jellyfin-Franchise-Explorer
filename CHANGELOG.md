# Changelog

## 0.2.0.0 — experimental source release, not approved for production
- Added embedded administration page to create and edit virtual franchise groups.
- Added simple virtual references to existing Jellyfin item IDs.
- Added metadata-only artwork fields and viewing-order labels/positions.
- Added JSON import/export backups and demo virtual groups.
- Replaced non-XML-serializable dictionary artwork fields.
- Added validation and GitHub Actions build pipeline.
- Added manually gated experimental release workflow to generate a real catalog manifest from a release ZIP.

**Not included:** native Franchises browsing tab, direct playback, automated Jellyfin item lookup, artwork upload/display, per-user timelines, or tested Jellyfin 12.2 runtime compatibility.
